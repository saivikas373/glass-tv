# Glass TV: conservative ad and tracking list (built from CleanYourTV's lists, MIT License, Copyright (c) 2026 Gathin)
# Only packages that CleanYourTV's device lists mark as ads, tracking or promo on several TVs, plus a short
# section per brand. Glass-Setup switches each one off ONLY if it is installed, with
#   pm disable-user --user 0 <package>      (never uninstalled; Glass-Restore turns them back on)
# Never on this list: Settings, setup, System UI, Play Services, Play Store, TV inputs/HDMI/Live TV,
# keyboard, Bluetooth/remote, audio, firmware updates, the stock launcher, voice search, streaming apps.
# "# quiet" = the TV's own system service turns it back on, so Glass won't show a repair banner for it.
